## 1. UI & Frontend (The "Desktop" part)

- WPF with MVVM: If you used XAML to build interfaces, this is your strongest skill.

- WinForms: If you built classic "drag-and-drop" Windows applications.

- XAML: The language used for designing the UI in WPF.

---

## 2. Backend & Data (The "Logic" part)

- ADO.NET: The classic way to connect to SQL Server.

- Entity Framework (EF6): The most common ORM (Object-Relational Mapper) used during those years.

- LINQ: Mentioning this shows you know how to handle data collections efficiently.

- WCF (Windows Communication Foundation): This was very popular in 2014-2018 for building SOAP/service-based communications.

---

## 3. Core C# Concepts

- Multithreading / TPL: Tasks and BackgroundWorkers were huge for keeping desktop UIs from freezing.

- Generics & Delegates: Fundamental C# concepts you definitely used.

---

## 4. C# --> Java (Springboot) 

- **Models** = Entities

- **Data/Repository** = Spring Data Repositories

- **ViewModels** = Controllers/Services (for UI state)
